# DDOS-Traffic-Classification
A project aiming to detect and classify Distributed Denial of Service traffic.

# Requirements
- Python 3.11.5
- NumPy 2.2.6
- Pandas 2.2.3
- Matplotlib 3.10.6
- PyTorch 2.8.0

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
